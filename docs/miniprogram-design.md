# Trail Master 小程序版设计文档

**版本**：v1.0（初版设计）
**日期**：2026-05-18
**状态**：设计中

---

## 一、设计目标

将现有 Streamlit 网页版（v1.2.5）改造为微信小程序，核心功能保留：
1. 上传赛道 GPX + 训练记录 FIT → 预测完赛时间
2. Garmin Connect 同步训练数据

**设计语言**：简洁、原生小程序风格，不要 Streamlit 搬家

---

## 二、导航结构

### 底部 Tab Bar（从左到右，4 个）

```
┌────────┬────────┬────────┬────────┐
│  数据  │  预测  │  设置  │  我的  │
│  📂    │  🏔️   │  ⚙️    │  👤    │
└────────┴────────┴────────┴────────┘
```

| Tab | 作用 | 核心操作 |
|-----|------|---------|
| **数据** | 管理本地存储的 GPX/FIT 文件 | 查看、添加、删除 |
| **预测** | 主页，系统介绍 + 开始预测 | 点击按钮执行预测 |
| **设置** | 为预测配置输入文件 | 选择 GPX 赛道 + FIT 训练记录 + 能力系数 |
| **我的** | Garmin 账号 + 活动同步 | 登录、筛选、下载、导入存储 |

## 三、页面详细设计

### Tab 1：数据（📂）

管理小程序本地存储的文件。

```
┌─────────────────────┐
│  我的数据            │
│                     │
│  赛道 GPX     [＋]  │
│  ─────────────      │
│  │ XX越野赛.gpx  🗑│ │
│  │ XX爬山赛.gpx  🗑│ │
│  │ XX马拉松.gpx  🗑│ │
│                     │
│  训练 FIT     [＋]  │
│  ─────────────      │
│  │ 5/12越野跑.fit 🗑│ │
│  │ 5/10跑步.fit   🗑│ │
│  │ 5/05越野跑.fit 🗑│ │
│  │ 5/03跑步.fit   🗑│ │
└─────────────────────┘
```

**功能点：**

- **分类展示**：GPX 和 FIT 分两个区块，各带独立标题和 [＋] 按钮
  - 赛道 GPX 区块：存放所有 GPX 赛道文件
  - 训练 FIT 区块：存放所有 FIT 训练记录
- **添加按钮 [＋]**：每个区块右上角有独立的 [＋] 按钮，点击后从手机本地选择对应类型文件导入
- **删除按钮**：每条记录右侧红色删除按钮
  - 点击后弹出确认框："确定删除此文件？"
  - 确认后删除，取消则不操作
- **文件信息**：显示文件名、距离、爬升、文件大小、导入时间
- **空状态**：没有文件时显示引导文字"点击 + 号添加文件"

**存储限制：**
- 微信本地存储上限 10MB
- 单个 GPX 约 10-200KB，单个 FIT 约 50-500KB
- 超限时提示用户清理旧文件

│                     │

│     道文件。        │

│     定对应赛道与个人│

**预测过程状态：**

点击「开始预测」后，在当前界面展示过程（不跳转 Tab）：
- 显示加载动画 + "预测中..."
- 调用后端 API 获取预测结果
- 完成后直接展示预测报告

**预测报告（核心输出物）：**

```
┌──────────────────────────┐
│  ✅ 预测完成              │
│                          │
│  [完成时间] [平均配速]    │
│  [平均速度] [总爬升]      │
│  ─────────────────       │
│                          │
│  [赛道概览][分段配速]     │
│  [战术建议][导出]         │
│  ─────────────────       │
│                          │
│  （4 个子 Tab 内容区）    │
│                          │
│  ─────────────────       │
│  [再次预测]               │
└──────────────────────────┘
```

**报告子 Tab 结构（对齐原 Streamlit 网页版）：**

**子 Tab 1：赛道概览**
- 左侧「赛道信息」：总距离、总爬升、总下降、海拔密度、难度评级
- 右侧「能力画像」：平均训练速度、P50 日常水平、P90 最佳状态、努力系数、策略

**子 Tab 2：分段配速**
- 表格：位置（起点/CP点/终点）、本段距离、累计距离、本段爬升、本段下降、本段时间、累计时间、平均速度
- 按 CP 点分段或按 5km 间隔分段

**子 Tab 3：战术建议**
- 配速策略：根据坡度和疲劳累积给出前半程/上坡建议
- 补给建议：根据预计用时给出能量胶数量、补给频率、饮水量

**子 Tab 4：导出**
- 生成分享卡片（wx.shareAppMessage，链接卡片形式，对方点开查看简化版结果页）
- 保存报告（HTML 格式完整预测报告，含分段配速和战术建议，可在浏览器中打开）

**预测报告与历史预测的关系：**

- 每次成功预测生成一份预测报告（结构化文档）
- 报告自动存入「历史预测」列表
- 历史预测列表显示：赛事名 + 预测时间 + 日期
- 点击历史预测的任意一条 → 打开该份完整预测报告（和预测完成时看到的是同一份）

**功能点：**

- **开始预测按钮**：点击后在当前界面执行预测过程，不跳转 Tab
- **预测过程**：加载动画 + 进度提示
- **预测报告**：4 个子 Tab（赛道概览、分段配速、战术建议、导出），对齐原网页版
- **再次预测**：返回初始状态，可重新配置
- **分享**：通过 wx.shareAppMessage 生成链接卡片分享到微信
- **历史预测**：最近 5-10 条预测报告索引，点击查看完整报告

### Tab 3：设置（⚙️）

为预测选择输入文件和参数。

```
┌─────────────────────────┐
│  预测设置                │
│                         │
│  选择赛道 GPX           │
│  ┌───────────┐ ┌──────────────┐
│  │ 存储选择  │ │ 本地文件选择 │
│  └───────────┘ └──────────────┘
│  当前：莫干山越野赛.gpx  │
│                         │
│  选择训练记录 FIT       │
│  ┌───────────┐ ┌──────────────┐
│  │ 存储选择  │ │ 本地文件选择 │
│  └───────────┘ └──────────────┘
│  已选：                 │
│  · 上周训练.fit         │
│  · 间歇训练.fit         │
│                         │
│  能力系数               │
│  保守 ←──●──→ 激进      │
│         1.0             │
└─────────────────────────┘
```

**功能点：**

- **GPX 选择**：两个来源入口
  - 「从存储选择」：弹出文件列表，从"数据" Tab 的本地存储中选择，单选
  - 「从本地文件选择」：调用手机文件选择器，导入 GPX 文件
  - 选中后显示完整文件名（非数量）
- **FIT 选择**：两个来源入口
  - 「从存储选择」：弹出文件列表，从"数据" Tab 的本地存储中选择，可多选
  - 「从本地文件选择」：调用手机文件选择器，导入 FIT 文件
  - 选中后逐条列出完整文件名（非数量）
- **能力系数滑块**：
  - 范围：0.8（保守）~ 1.2（激进），默认 1.0
  - 滑块下方显示当前值
  - 作用：乘以预测时间，调整预测结果

## 五、文件存储方案

### 本地存储（wx.setStorageSync）

| 数据类型 | 存储 Key | 格式 | 预估大小 |
|---------|----------|------|---------|
| GPX 文件 | `gpx_{id}` | Base64 或 ArrayBuffer | 10-200KB/个 |
| FIT 文件 | `fit_{id}` | Base64 或 ArrayBuffer | 50-500KB/个 |
| 文件索引 | `file_index` | JSON 数组 | <1KB |
| 预测历史 | `prediction_history` | JSON 数组 | <10KB |
| Garmin Token | `garmin_token` | JSON | <1KB |
| 用户设置 | `settings` | JSON | <1KB |

### 存储管理

- 总容量上限：10MB
- 每次导入文件时检查剩余空间
- 空间不足时提示："存储空间不足，请清理旧文件"
- 文件索引记录每个文件的 id、名称、类型、大小、导入时间

## 六、交互细节

### 确认弹窗

| 场景 | 弹窗内容 | 按钮 |
|------|---------|------|
| 删除文件 | "确定删除此文件？删除后无法恢复" | [取消] [删除]（红色） |
| 退出登录 | "确定退出 Garmin 账号？" | [取消] [退出] |
| 存储空间不足 | "存储空间不足，请清理旧文件后重试" | [去清理] |
| 未选文件就开始预测 | "请先选择赛道 GPX 和训练记录 FIT" | [知道了] |

### 加载状态

| 场景 | 显示 |
|------|------|
| Garmin 登录中 | 按钮显示"登录中..." |
| Garmin 同步中 | 转圈 + "同步中..." |
| 预测计算中 | 转圈 + "预测中..." |
| 文件导入中 | 进度条 |

### 错误处理

| 错误 | 提示 |
|------|------|
| 网络断开 | "网络连接失败，请检查网络" |
| Garmin 登录失败 | "账号或密码错误，请重试" |
| Garmin Token 过期 | "登录已过期，请重新登录" |
| GPX 文件格式错误 | "文件格式不正确，请选择 GPX 文件" |
| FIT 文件格式错误 | "文件格式不正确，请选择 FIT 文件" |
| 预测失败 | "预测出错，请检查文件后重试" |

## 七、与网页版的功能对照

| 功能 | 网页版（v1.2.5） | 小程序版 | 变化 |
|------|-----------------|---------|------|
| GPX 上传 | 文件选择器 | 从本地/存储选择 | 适配手机 |
| FIT 上传 | 文件选择器 | 从本地/存储选择 | 适配手机 |
| 能力系数 | 滑块 | 滑块 | 不变 |
| 预测算法 | LightGBM | 需后端或 WASM | 架构变化 |
| Garmin 登录 | Streamlit 表单 | 小程序弹窗 | UI 变化 |
| 活动筛选 | Sidebar | Tab 内筛选 | 布局变化 |
| 活动下载 | 直接下载 | 保存到手机/存储 | 路径变化 |
| 结果展示 | Streamlit 组件 | 原生页面 | UI 变化 |
| 数据存储 | 无（临时文件） | 本地持久化 | 新增功能 |
| 分享 | 无 | 微信分享卡片 | 新增功能 |
